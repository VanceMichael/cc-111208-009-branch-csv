# 预约导出接收规则

配置明确编码，或给出 utf-8-sig、gb18030 等候选；分隔符也可给候选。引号为双引号，内部双引号以两个双引号转义。只有唯一合法候选才能自动选择；ASCII 同时满足两个编码时是歧义，不用默认值猜。按字节分块读取，源身份绑定完整 SHA256 和映射版本，而不是路径。逻辑记录可跨 CRLF 多行，保存包含终止符的半开字节区间 [start,end)，物理行范围含首尾且从 1 起算；文件开头 BOM 不属于表头区间，其他位置不能忽略 BOM。

映射 v1 的字段是 bookingId、date、region、note，日期为 ISO YYYY-MM-DD，业务键非空。仅与确认表头逐字段一致的重复表头跳过。结构/列数错误、坏日期进入隔离；同预约号不同规范内容形成冲突，不截列、不补空、不覆盖。

复核记录只作不可变字段覆盖，绑定源摘要、原始记录区间和映射版本；任一变化都不能沿用旧决定，原始文件不修改。检查点必须和完整逻辑记录的业务/隔离结果一起提交。fixtures 有跨行 CRLF、错日期、GB18030、ASCII 歧义及错宽数据；解码错误不能替换或忽略。现有 preview 只做明确编码/方言的查看，不是增量接收。
