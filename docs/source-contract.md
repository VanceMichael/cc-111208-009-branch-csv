# 预约导出接收约定

本文件描述编码、方言与字节定位的规则；业务流程与隔离原因见 `docs/acceptance.md`。

## 编码

支持的候选编码：`utf-8-sig`、`gb18030`。配置可显式指定，或提供候选集合。

- 判定只读取文件开头的有界样本（默认 4 KiB），不会把整个文件读入内存。
- 候选合法要求：样本严格解码（出现解码错误即不合法，绝不替换或忽略），且首条记录在候选分隔符下至少切出两个字段。
- 只有唯一合法候选取值时自动采用；多个合法候选报告歧义并列出候选，不默认逗号、不默认 UTF-8。
- ASCII 数据同时满足 UTF-8 与 GB18030，按规则属于歧义。

## 方言

- 分隔符为单个可打印 ASCII 字节或 TAB，候选默认 `,` `;` `\t`，也可显式给出。
- 默认候选都避开了 GB18030 的尾字节区间（0x40–0xFE）；若显式指定落在该区间的分隔符（如 `|`），切裂多字节字符会表现为严格解码失败并被隔离，不会静默损坏文本。
- 引号为 `"`，字段内 `""` 表示一个字面双引号。
- 字段可跨 CRLF 或多行；每条逻辑记录以 `\r\n`、`\n` 或 `\r` 结尾。
- BOM 只在文件起始处处理。

## 字节与行定位

- 每条逻辑记录保存半开字节区间 `[start, end)`，终止符包含在区间内。
- 物理行范围从 1 起算、含首尾；引号内的换行同样计入。
- 引号未闭合的记录区间延伸到文件末尾，标记为不平衡并停止后续解析。
- 最后一条记录可以没有终止换行，仍视为完整。
- 表头区间由 `(encoding, delimiter, header fields)` 决定，映射版本据此计算。

## 分块

`branchcsv.scan.scan` 按固定块读取，只保留当前块与当前逻辑记录。块大小可配置，扫描结果与块大小无关（见测试 `test_scanning_is_independent_of_chunk_size`）。

## 失败语义

| 情形 | 行为 |
| --- | --- |
| 候选编码均非法 | `dialect_unresolved`，附各候选原因 |
| 多个合法候选 | `encoding_ambiguous` / `delimiter_ambiguous`，附候选清单 |
| 表头字段缺失、重复或多余 | `mapping_unresolved` |
| 记录无法严格解码 | 该记录隔离为 `decode_error` |
| 文件在中段出现 BOM | 该记录隔离为 `mid_file_bom` |

现有 `preview` 只做明确编码/方言的查看，不是增量接收。
